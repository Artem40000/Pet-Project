# Pet-Project(Used: Django, Python, PostgreSQL, Docker, Docker-compose, REST API, HTML, CSS, JS, Ollama).
1)AiAgent.
На главной странице есть поле ввода, когда в него введено значение и нажат Enter/Кнопка отправки, появляется отправленное сообщение и агент начинает работу("Думает"). ИИ-Агент на Ollama с логикой парсинга данных с интернета по заданному запросу, когда данные показаны на форме, их/своё сообщение можно скопировать.



2)AiProject.
На главной странице по середине вверху представлен текст название LLM и её модель: "Ollama" "Model name: llama3".
По умолчанию стоит llama3:latest, но в верхнем левом углу можно поменять модель на более быструю под названием qwen2.5:7b, умная это llama3 (Есть мизерные анимации). Также в том же углу чуть левее есть кнопка которая позволяет создать новый чат.
По середине поле ввода запроса.
После отправки запроса также есть анимация кубиков, которая показывает что модель строит ответ.

Когда пользователь просто задает/просит объяснить что-то/спрашивает, то модель отвечает ему по его запросу, но когда пользователь просит объяснить/написать код/править код и т.д из темы программирования, то вместе с ответом модели она еще выдаёт Теорию и ниже теории Бокс специально для кода. Код в нём тоже можно скопировать как и своё же сообщение и ответ модели. В бокс добавлено в верхний левый угол определение языка программирования.


3)Cases.
Регистрация и Авторизация пользователя, после которой на выбор для открытия доступны 3 кейса.
После нажатия на кейс появляются: предметы которые могут выпасть с этого кейса, при нажатии на кнопку "Открыть", на рандом выбирается 1 предмет и попадает в инвентарь к пользователю. REST API(Добавление/удаление предметов в кейсах).



4)Chat.
Слабая "нейронка". Логика: парсинг данных по определенному запросу(Доступные запросы в левом верхнем углу под знаком "?"(Кликабельно)).



5)DockerSix.
Регистрация и Авторизации, после них идёт страница на которой: Информация о пользователе, Изменения его данных, Удаление пользователя, Переход на страницу регистрации.
Есть Docker, Docker-Compose с Томом.



6)NightMare.
После страницы -> http://localhost:8000/Nightmare/.
После нажатия на кнопку "GO" идёт Регистрация и Авторизация аккаунта. После идёт главная страница с информацией(Градусы, Скорость ветра) о погоде в странах: Россия,Америка,Швеция, в каждой стране информация о погоде в 4 городах. На левой панели есть кнопка 'Account', если на нее нажать, то можно посмотреть/изменить/удалить информацию об аккаунте



7)NoneProject.
Регистрация или Авторизация. После идёт страница на которой внизу есть меню с выбором: 
1)Создание задач, можно увидеть/создать/удалить свои задачи.
2)Меню пользователя где можно увидеть/удалить/редактировать данные об аккаунте.
3)ИИ-Агент. Агент с проекта AiAgent.
4)Home переносит на страницу Регистрации.



8)Pet-Project.
Регистрация и Авторизация с возможностью изменения и удаления пользователя. Есть REST API (Swagger), которое позволяет: удалять всех/одного пользователя, изменять данные о пользователе, добавлять пользователя, выводить список всех/одного пользователя. База данных не вписана.


9)ProjOnCtk.
Проект на Python с использованием библиотеки CustomTkinter(Ctk). 
Запустить main.py. После запуска идёт окно с регистрацией пользователя, в правом верхнем углу можно войти в аккаунт. После регистрации/авторизации идёт окно где можно изменить/удалить данные об аккаунте.



10)Test.
Регистрация и Авторизация. После идёт страница где можно: На левой панели есть кнопки(Account, Tasks, Conversion). По нажатию на каждую:
Account: Изменить/удалить данные об аккаунте.
Tasks: Посмотреть/создать задачу(и) (Название, Описание, время).
Conversion: Переводит разные единицы измерения, пока что, представлены только Длина(Сантиметры, метры, километры) и Вес(Граммы, килограммы, тонны).



11)ToDoList.
Регистрация и Авторизация после которой идёт страница с возможностями: посмотреть/удалить/изменить свои данные аккаунта, вывести все свои задачи, создать задачу.



12)WeatherProject.
Погода(Температура и Скорость ветра) с локациями, информация с открытого API (OpenMeteo). Доступные локации: Россия: Москва, Казань | Америка: Нью-Йорк, Чикаго.
