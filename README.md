# Pet-Project
1)Pet-Project на Django. 
Pet-проект на Django. Регистрация и авторизация с возможностью изменения и удаления пользователя. Есть REST API (Swagger), которое позволяет: удалять всех/одного пользователя, изменять данные о пользователе, добавлять пользователя, выводить список всех/одного пользователя. База данных не вписана.


2)WeatherProject на Django.
Погода(Температура и Скорость ветра) с локациями, информация с открытого API (OpenMeteo). Доступные локации: Россия: Москва, Казань | Америка: Нью-Йорк, Чикаго.

3)Projectt:
Сайт с регистрацией и авторизацией. После регистрации для чтения на выбор есть 4 книги: Иван Тургенев "Муму", Кир Булычев "Поселок", Лора Кейли "Жатва", Кэтрин Парди "Лес Гримм".
Также на этой странице можно изменить данные об аккаунте, или удалить его, или перейти на страницу регистрации.

4)ToDoList
Список задач. Можно добавлять/удалять задачи. В задачах есть: Название, Описание, Время. 

5)DockerSix
Pet-Project. Регистрация и Авторизации, после них идёт страница на которой: Информация о пользователе, Изменения его данных, Удаление пользователя, Переход на страницу регистрации.
Есть Docker, Docker-Compose с Томом.
Запустить: docker-compose up
Host: localhost:8000
